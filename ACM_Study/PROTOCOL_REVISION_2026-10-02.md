# Protocol revision record — 2026-10-02

## Study
**Where Does Institutional Constitution Fail? An Empirical Test of the Seven-Layer Energy Digital-Twin Model**

## Reason for revision
The original expert-study protocol used a balanced incomplete-block design (CONTROL + 5 faults per participant). The live Google Forms instrument actually presents CONTROL + all 10 fault scenarios to each eligible participant. Eight submissions existed at the time this mismatch was identified; six passed the relevance screener and two were screened out.

## Frozen correction
From protocol v2.0, Phase 2 is a complete within-participant repeated-measures expert scenario study. Every eligible participant evaluates all 11 scenarios.

## Primary endpoint
The live institutional-consequence item has three levels: Yes; No; Not sure / insufficient information. The primary paired exact McNemar contrasts use only explicit Yes/No CONTROL–fault pairs. Uncertain responses are not recoded. Their frequencies are reported descriptively and denominators are reported for every contrast.

## Multiplicity
Ten CONTROL-vs-fault primary contrasts; Holm adjustment in final inference. Bonferroni alpha=.005 is retained only for conservative prospective power sizing.

## Sample-size implication
The original design required 270 complete experts because each expert saw only half of the fault conditions. Under the implemented complete design, every complete eligible expert contributes a potential pair for every fault. Under the original prospective McNemar assumptions, approximately 135 evaluable pairs are required. Because uncertain responses can make individual contrasts non-evaluable, the operational recruitment target is set to **160 complete eligible experts**, with final power reported using actual evaluable denominators. This target was set without using outcome-effect estimates from the first eight submissions.

## Phase naming
- Phase 1: controlled fault injection.
- Phase 2: expert scenario study.
- Phase 3: independent institutional adjudication.

## Audit principle
The legacy BIBD notebook is retained unchanged. No historical file is rewritten to imply that the implemented design had always been planned.
