# ACM Energy Digital-Twin Failure Study

Working research package for **Where Does Institutional Constitution Fail? An Empirical Test of the Seven-Layer Energy Digital-Twin Model**.

## Study architecture
1. `00_environment_and_source_audit.ipynb` — provenance and source audit.
2. `01_fault_injection_experiment.ipynb` — Phase 1 controlled fault injection.
3. `02_expert_scenario_study.ipynb` — Phase 2 complete within-expert scenario protocol v2.0.
4. `03_institutional_adjudication.ipynb` — Phase 3 independent institutional adjudication.
5. `02_expert_scenario_study_legacy_bibd.ipynb` — preserved original BIBD protocol for auditability.
6. `PROTOCOL_REVISION_2026-10-02.md` — transparent protocol-deviation record.

## Important data rule
Raw participant-response exports are **not committed** to this public repository. Keep identifiable or potentially re-identifiable human-subject data outside GitHub unless the approved ethics/data-management plan explicitly permits release. Only de-identified, publication-ready derivatives should be added when appropriate.
